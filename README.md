# nyanners
#### not to be confused with the vtuber of the same name

a very primitive game engine designed to ease my transition from roblox to standalone, thus mostly following roblox's tree, instance, and etc structure and formats (but deviating enough as to not let roblox's own design limitations get in the way)

currently compiles on windows and linux. macOS never™ unless someone with a mac decides to try and make it compile there (although i would not recommend because god you do not want to be maintaining this code)

current list of features:
- 2d/3d opengl renderer
- lua scripting with very basic reflection
- veery primitive 3d model support, currently only pre-triangulated obj is supported, non-triangulated objs WILL look broken
- ui with primitive text, buttons, containers and some components (aka UIAspectRatioComponent)
- very primitive editor-ish debug ui, actual editor eta never (probably)
